RUNG ONE

What if the thing you typed into a chat window was the cheapest leverage you'd ever buy?

↑ FIRST RUNG ~5 MIN TO START

01/07

Prompting.

Claude.ai ChatGPT a browser tab

You open a chat window and ask for things. The model does the work. You do the steering. A sharp prompt against a frontier model is still the highest leverage-per-minute most people will ever touch.

SEED EXAMPLE · GENERIC
"Summarise this PDF and pull out the three numbers I should be worried about."
RUNG TWO

What if the answer wasn't a paragraph, but a working website?

↑ SECOND RUNG ~AN AFTERNOON

02/07

Vibe coding.

Lovable v0 Bolt

You describe an app. A working app comes out. You never open a terminal. The output is a real URL, with a real database, on the real internet. The part of your brain that used to say "I'd need a developer for that" goes quiet.

SEED EXAMPLE · GENERIC
"Make a one-page site that takes RSVPs to a dinner party and texts me when someone replies."
RUNG THREE

What if it could touch the code you already had?

↑ THIRD RUNG ~A WEEKEND

03/07

Coding agents.

Claude Code Cursor your terminal

The agent reads your whole repo, writes patches, runs tests, reports back. You spend more time reviewing than typing. It becomes the junior who never sleeps, and never resents the legacy.

SEED EXAMPLE · GENERIC
"Migrate this codebase from Pages Router to App Router. Tell me what you couldn't translate."
RUNG FOUR

What if the code remembered why you wrote it?

↑ FOURTH RUNG ~A FEW EVENINGS

04/07

Repo as memory.

CLAUDE.md /prompts /docs markdown

You stop telling the model what you do, and start storing it. A CLAUDE.md at the root. A prompts folder. A docs folder that is the architecture, not the afterthought. The repo becomes a second brain the model can read in one breath.

SEED EXAMPLE · GENERIC
"Read CLAUDE.md, then propose a refactor that respects every rule it lists."
RUNG FIVE

What if the model didn't live in a chat window at all?

↑ FIFTH RUNG ~A WEEK

05/07

APIs.

anthropic SDK webhooks cron

The model is a function in your code. Fired from a webhook, a cron, a click. It sits next to Postgres and Stripe as just another primitive. Anything with a network connection can be a little smarter on its own.

SEED EXAMPLE · GENERIC
"Every new support ticket gets read, classified, and tagged before a human ever sees it."

THE LADDER PAYS OFF

06

↑ SIXTH RUNG WHERE THE MODEL STARTS REMEMBERING YOU

Skills.

Memory. Retrieval. Skills. The model carries your context, your house style, your standard operating procedure with it. A skill is a small, named bundle of instructions that changes what the model does, every single time the trigger fires.

"A prompt is something you write once. A skill is something the model does forever."

YOUR SKILL SHELF · A FEW EXAMPLES
SKILL · 01 house-style-writer
FIRES WHEN you ask Claude to draft any external-facing copy. It lifts tone, banned words, and your three rhetorical tics from a single source file.
SKILL · 02 monday-digest
FIRES WHEN you say "what happened last week." It pulls Linear, Stripe, and Slack into the same three-paragraph brief, every time, in the same shape.
SKILL · 03 contract-redline
FIRES WHEN a PDF lands in a folder. It flags clauses against your playbook and drafts the email to your lawyer with the diff attached.

Integrated systems.
